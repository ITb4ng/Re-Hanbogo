
# RE:HANBOGO

### 알아보고, 입어보고, 둘러보고.

한복의 전통적 가치와 현대 K-콘텐츠를 연결하여, 사용자가 직접 배우고 체험할 수 있는 인터랙티브 문화 플랫폼입니다.

**프로젝트 유형:** 선남선녀 팀 프로젝트의 개인 리뉴얼  
**진행 상태:** Planning & Research (2026.11~)

---

## 01. 개발 배경

기존 선남선녀 프로젝트는 한복을 소재로 한 서비스의 **사업적 가치와 수익화 가능성을 제시하는 데 초점을 맞춘 팀 프로젝트**였습니다.

이번 리뉴얼에서는 기존 프로젝트에서 발견한 가능성을 사용자 경험으로 구체화하고자 합니다.

현대 K-콘텐츠를 통해 한복에 대한 관심을 높이고, 일상에서 접할 기회가 상대적으로 적어진 우리 고유 의복의 역사와 문화적 이해가 실제 착용과 체험으로 이어질 수 있는 웹서비스를 구현하는 것이 목표입니다.

## 02. 프로젝트 목표

**발견하기 → 알아보기 → 입어보기 → 경험하기**

K-콘텐츠를 통해 한복에 대한 관심을 유도하고, 역사와 복식에 대한 학습을 실제 체험까지 연결하는 사용자 경험을 설계합니다.

## 03. 핵심 구현 범위

- **K-콘텐츠:** 현대문화에서 재해석된 한복 사례 탐색
- **한보고:** 한복의 역사·종류·구성요소 학습
- **커스터마이징:** 2D 기반 한복 색상 및 구성요소 조합
- **문화 탐색:** 궁궐과 한복 체험 장소 및 문화행사 정보

초기 MVP는 한복 아카이브와 커스터마이징을 중심으로 구현하며, 문화 탐색은 경복궁·종로 일대로 범위를 제한합니다.

## 04. 사용자 경험 기반 설계

실제 사용자 관점에서 서비스를 설계하기 위해 **경복궁·광화문·종로 일대 현장 조사**를 계획하고 있습니다.

한복 대여점 탐색부터 착용, 궁궐 관람까지 직접 체험하며 사용자의 정보 탐색 과정과 불편함을 조사하고자 합니다.

이를 바탕으로 초기 기획 가설을 검증하고, 실제 사용자에게 필요한 기능과 UI/UX를 개선할 예정입니다.

## 05. 개발 계획

1. 기존 프로젝트 분석 및 요구사항 정의
2. 현장 조사와 UI/UX 설계
3. K-콘텐츠 및 한복 아카이브 구현
4. 한복 커스터마이징 및 문화 탐색 기능 개발
5. 사용자 테스트, 성능 개선 및 배포

### 기술 스택 (예정)

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **Interactive UI:** SVG, CSS Animation
- **Map:** Kakao Maps API
- **Deployment:** Vercel

---

> 현재 기획 단계이며, 구현 범위와 기술 구성은 사용자 조사 및 개발 과정에 따라 조정될 수 있습니다.
